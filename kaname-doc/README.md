## 現在の開発作業に適用する制約

外部に影響する Git の書き込み操作は行わない。GitHub 上の fork 作成・push・PR 作成・マージ・公開、既存リポジトリの remote 設定変更、既存履歴の書き換えは行わない。2026-10-02 にユーザーが「一旦今のPoC状態をコミットしてほしい」と指示したため、今回の PoC 基準を保存するローカルコミットは許可された。これは push や、その後の作業での自動コミットを許可するものではない。

この制約は開発を担当するエージェントの現在の作業に適用する。完成後の KANAME に実装する「人の承認後に PR をマージする機能」とは別の話であり、その機能の検証にはモックを使う。
